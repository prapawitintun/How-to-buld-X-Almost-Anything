# Build for Humanity — เรียนรู้เทคโนโลยีด้วยการสร้างสิ่งที่ช่วยผู้คน

**รวบรวมโดย Prapawit Intun — MIT Affiliate**  
เพื่อศึกษาเทคโนโลยีในอนาคต ผ่านการสร้าง ทดลอง วัดผล และแบ่งปัน

ฉบับนี้มี **60 หัวข้อ ใน 8 กลุ่ม**, **บทฝึก Python ที่รันได้ 6 บท** และ **หัวข้อหุ่นยนต์ฮิวแมนนอยด์ 12 เรื่อง**

## เพิ่มอะไรจากชุดก่อน

- เก็บหัวข้อเดิม 40 เรื่อง พร้อมโค้ดสร้างแผ่น คำนวณรอยต่อ และจัดแผ่น
- เพิ่ม humanoid: รูปร่างและโครงสร้างข้อ, คิเนมาติกส์, dynamics/contact, การทรงตัว, การเดิน, การหยิบจับ, teleoperation, imitation learning, reinforcement learning, sim-to-real และการกำกับโดยมนุษย์
- เพิ่ม 8 หัวข้อเพื่อประโยชน์สาธารณะ เช่น เครื่องมือที่เข้าถึงได้ การซ่อม การติดตามสิ่งแวดล้อม พลังงานชุมชน การผลิตหมุนเวียน และการประเมินกับผู้ใช้
- เชื่อมงาน [build-your-own-x ของ CodeCrafters](upstream/README.md) โดยให้เครดิตและบันทึก commit ต้นทาง ไม่คัดลอกชุดบทเรียนทั้งหมดมาเป็นผลงานของเรา

## เริ่มจากของที่รันได้

```bash
python labs/04-limb-kinematics/main.py
python labs/05-static-balance/main.py
python labs/06-human-supervision/main.py
python scripts/validate.py
```

บทฝึกใหม่คำนวณตำแหน่งแขน/ขา ตรวจพื้นที่รองรับแบบสถิต และจำลองการอนุมัติงาน/หยุด/รีเซ็ต ใช้ Python standard library ไม่ต้องมีหุ่นยนต์หรือ API key ผลรูป SVG อยู่ใน `outputs/`

นี่เป็นฐานการเรียนรู้ ไม่ใช่ฮิวแมนนอยด์ที่เดินได้สำเร็จแล้ว [HUMANOID.md](HUMANOID.md) อธิบายขั้นต่อไป และ [IMPACT_ROADMAP.md](IMPACT_ROADMAP.md) อธิบายว่าจะเปลี่ยนโครงการให้เป็นประโยชน์ที่วัดผลได้อย่างไร

เส้นทางที่เหมาะกับงานของ Pam: **เสียงชุมชน → ข้อกำหนดงานที่มนุษย์ตรวจ → planar parts → การจัดวาง → หุ่นยนต์ช่วยประกอบใน simulation → ทดสอบจริงเป็นขั้นตอน** โดยเริ่มจากงานหยิบวางง่ายและขอบเขตชัดเจน

ชุดนี้เป็นผลงานการรวบรวมอิสระ ไม่ใช่สิ่งพิมพ์อย่างเป็นทางการของ MIT ดู [สารบัญเต็ม](README.md) และ [แหล่งที่มา](SOURCES.md)
