# Original learning collection

[CodeCrafters build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) is the original reference for software reconstruction tutorials. Its authors and contributors retain credit for their collection.

Recorded commit: `aa17439b62f384511a5561ce308e9598b94d8989`. This package adds independently written physical-making, humanoid, and public-benefit learning paths alongside that reference.

The checked repository metadata had no declared license and its root contained no license file. This archive therefore links to the original rather than redistributing its README, banner, or tutorial collection under the local license.

To access the complete original in a separate local checkout, run `python scripts/fetch_upstream.py`. This needs Git and internet access, fetches the recorded commit, and does not execute upstream code. Follow each linked author's terms for their material.
