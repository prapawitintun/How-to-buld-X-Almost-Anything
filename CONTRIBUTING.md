# Contributing

Start with one useful, reproducible lesson. Improve an existing category before creating a duplicate.

For a resource, provide its original author or organization, URL, resource type, language, level, access requirements, and relevant license. Label commercial services, paid material, and tool documentation clearly. Prefer a direct tutorial over a general landing page.

For a lesson, provide prerequisites, exact commands, sample inputs, expected outputs, failure cases, and limitations. Mark untested physical claims. Never label geometric success as a physical test.

Update `catalog.json`, the category page, and README together. Run `python scripts/validate.py`. Run the link checker when changing URLs; investigate blocked responses before removing a resource. Do not copy external text, code, or images without checking its license.

Do not commit keys, personal records, participant identities, or private research data. Participation examples should use synthetic data or documented consent and appropriate access controls.
