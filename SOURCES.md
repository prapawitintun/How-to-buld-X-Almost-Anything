# Sources, attribution, and validation

## Original collection

[CodeCrafters build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) remains an attributed upstream reference. See [the pinned record](upstream/README.md). Its README, banner, and resource collection are not redistributed in this archive.

## Local additions

The earlier package has 40 categories and three Python labs. This edition adds 20 independently written challenges, three local labs, and evaluation guides. Original repository text and code retain the local MIT License; externally linked materials retain their own terms.

## Reference verification

On 2026-10-15, an automated HTTP check covered **83 unique catalog URLs** across **112 resource entries**. All returned successful HTTP responses. This is a reachability check, not a guarantee of readable content, current compatibility, educational quality, or successful reproduction.

An access-challenge page was observed at the ROS documentation site during web inspection. The [ROS documentation repository](https://github.com/ros2/ros2_documentation) is also linked. External robot-learning frameworks were not installed or benchmarked for this release.

## Local executable validation

The six original teaching labs were run for the earlier release. The integrated seventh lesson adds kinematic and dependency checks. The validator checks catalog consistency, local links, geometry, fit intervals, packing feasibility and its sample baseline, kinematic Jacobians against finite differences, signed support-region margins, invalid task-state transitions, and CAD-to-robotics unit conversion, inverse kinematics, and dependency failures. No physical robot, material test, field study, or full humanoid controller was evaluated.
