# Build your own: Data visualization

Track: AI & Data · Level: starter · ID: LL-008

## Build challenge

Build a participation chart that links every mark back to a source record.

## Method

1. Read the linked introduction or relevant documentation. Record which versions you use.
2. Implement the smallest example that meets the challenge. Keep inputs and outputs explicit.
3. Try one normal input, one boundary case, and one invalid input.
4. Compare the result with a stated reference or baseline, then document limitations.

## Deliverables

- A runnable example or documented physical prototype.
- A README with prerequisites, steps, units, and expected results.
- An evidence record with input, observation, and failure cases.
- Source attribution and applicable licenses.
